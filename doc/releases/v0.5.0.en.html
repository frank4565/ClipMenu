ClipMenu 0.5.0

The first modern Swift release of ClipMenu, with native macOS windows and support for Intel and Apple silicon Macs running macOS 12 or later.

Install this version manually

When upgrading from an older Objective-C version, quit ClipMenu and install this release manually. The original updater uses a different feed and trust key and cannot deliver this first Swift release. Supported legacy history, snippets, actions, and preferences can be loaded by the new app.

The app uses a local ad-hoc code signature. If macOS blocks its first launch, use the app-specific Open Anyway option described in Apple's opening instructions. Published update ZIPs use separate Sparkle Ed25519 signatures.

What changed

  • Native windows: modern preferences and snippet editing, with updated English and Japanese interfaces.
  • Responsive preferences: faster tab switching while keeping each pane's own window height. Tall panes fit within the usable screen area and scroll to their last controls, with a native scrollbar indicator during scrolling. Action lists scroll independently.
  • Clipboard history: restored history grouping, duplicate handling, ordering, and menu controls. Image entries offer a larger preview on hover.
  • Snippets: edit and organize folders, search saved text, reorder items, and import or export snippets in the native editor.
  • Actions: manage action folders and modifier-click mappings, and use built-in, bundled, or user JavaScript actions. Pending edits survive tab changes; committed action edits survive reopening preferences.
  • Shortcuts and paste: configure global menu shortcuts and automatic paste, with an Accessibility permission status and setup controls.
  • Capture controls: choose which clipboard types to store and exclude selected applications. Text, rich text, PDF, files, URLs, and images remain supported.
  • Future updates: Sparkle 2 replaces the legacy updater and uses this fork's new update feed. After this manual installation, compatible future releases can use its update, installation, and relaunch flow, with optional pre-release updates.
