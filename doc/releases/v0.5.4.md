# ClipMenu 0.5.4

This patch fixes history-menu sequence labels. It supports **macOS 12 or later** on **Intel and Apple silicon** Macs. **ClipMenu 0.5.0–0.5.3 users can update through Sparkle normally.**

## Changes

- With numbering starting at 1, the tenth history item in each group of ten now shows **10.** instead of **0.**, both inline and in submenus.
- **Command–0** remains the keyboard shortcut for the tenth history entry. Numbering starting at 0 is unchanged.

## Validation

The Debug build and all **seven focused MenuNumberingSurface runtime checks** passed.

- 履歴全体の 10 番目の項目のキーボードショートカットは引き続き **Command–0** です。0 から始める連番表示は変更ありません。
