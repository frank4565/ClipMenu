ClipMenu 0.5.2

メニューの Command と数字キーによる選択、および自動ペーストの遅延を修正したパッチリリースです。macOS 12 以降の Intel Mac と Apple シリコン搭載 Mac に対応します。

アップデート

ClipMenu 0.5.0 と 0.5.1 からは Sparkle で通常どおり更新できます。以前の Objective-C 版から更新する場合は、ClipMenu を終了して、このリリースを手動でインストールしてください。従来のアップデータとは更新フィードと検証キーが異なります。

アプリは引き続きローカルのアドホック署名を使用し、Apple Developer ID による署名や公証は行いません。公開する更新 ZIP は、別途 Sparkle の Ed25519 署名で検証します。

主な変更点

  • メニューのショートカットとペースト：Command と数字キーで対応する項目を選択し、メニューを閉じるようにしました。自動ペーストが有効でアクセシビリティ権限が許可されている場合、追加のキー操作を待たずに選択した項目をペーストします。
  • 履歴の記録：既存の履歴項目を選択した際に、そのクリップボードへの書き込みを再度記録しないようにし、不要な履歴保存とメニューの再構築を防ぎました。その後の外部アプリからのコピー、スニペット、アクションの結果は通常どおり履歴に記録されます。
  • バックグラウンド処理：履歴のエンコードと書き込みをバックグラウンドで行い、ペースト中のクリップボード監視とメニュー再構築を完了まで延期します。既存の履歴 ID と保存形式を維持し、終了時の最終保存は保留中の書き込みの後に実行します。

検証

ユニットテストは 111 件すべて成功し、失敗はありませんでした。問題が発生していた macOS 27.0.1 の MacBook Air で、Command–1 による選択と Safari のアドレスバーへの自動ペーストが動作することを、ユーザーが beta 4 で確認しました。
