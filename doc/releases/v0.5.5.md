# ClipMenu 0.5.5

This patch restores the original history-menu foldering. It supports **macOS 12 or later** on **Intel and Apple silicon** Macs. **ClipMenu 0.5.0–0.5.4 users can update through Sparkle normally.**

## Changes

- History items beyond `Number of items place inline:` now always appear inside range submenus, even when they fill only part of a folder page. With an inline count of 10 and twenty history items, items 1–10 stay inline and items 11–20 land in an **`11 - 20`** submenu.
- Previously, overflow that fit within one full page stayed flat at the menu's top level, so no folder appeared until history exceeded twice the inline count.

## Validation

The Debug build and the full unit test suite passed, including the updated history-menu grouping tests and MenuSurface runtime checks.
