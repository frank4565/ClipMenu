# ClipMenu 0.5.0

The first modern Swift release of ClipMenu brings native macOS preferences and snippet editing to **macOS 12 or later**, with support for **Intel and Apple silicon** Macs.

**Install this version manually when upgrading from an older Objective-C version.** Quit ClipMenu before replacing the app. The original updater uses a different feed and trust key and cannot deliver this first Swift release. Supported legacy history, snippets, actions, and preferences can be loaded by the new app.

The app uses a local **ad-hoc code signature**. If macOS blocks its first launch, use the app-specific **Open Anyway** option in [Apple's opening instructions](https://support.apple.com/en-us/102445). Published update ZIPs use separate Sparkle Ed25519 signatures.

## Changes

- Modern preferences and snippet windows with updated English and Japanese interfaces.
- Faster preference tab switching, while retaining a different height for each pane. Tall panes fit the usable screen area and scroll to their last controls, with a native scrollbar indicator during scrolling. Action lists retain independent scrolling.
- Restored history grouping, duplicate handling, ordering, and menu controls, plus larger image previews on hover.
- Snippet folders, search, reordering, and import/export in the native editor.
- Editable action folders and modifier-click mappings, with built-in, bundled, and user JavaScript actions. Pending edits survive tab changes, and committed actions survive reopening preferences.
- Configurable global menu shortcuts and automatic paste, with Accessibility permission status and setup controls.
- Clipboard-type filters and excluded applications, preserving support for text, rich text, PDF, files, URLs, and images.
- Sparkle 2 and a new update feed for compatible future releases, including installation, relaunch, and optional pre-release updates after this manual installation.

## 日本語

Swift で刷新した ClipMenu の最初のリリースです。**macOS 12 以降の Intel Mac と Apple シリコン搭載 Mac** に対応します。

**以前の Objective-C 版からの更新は手動でインストールしてください。** ClipMenu を終了してからアプリを置き換えてください。従来のアップデータとは更新フィードと検証キーが異なるため、最初の Swift 版は従来の自動更新では配信できません。対応する旧形式の履歴、スニペット、アクション、環境設定は新しいアプリで読み込めます。

アプリはローカルの**アドホック署名**を使用します。初回起動が macOS にブロックされた場合は、[Apple の起動手順](https://support.apple.com/ja-jp/102445)に従い、このアプリに対して**「このまま開く」**を選択してください。公開する更新 ZIP は、別途 Sparkle の Ed25519 署名で検証します。

- 環境設定とスニペット編集を macOS 標準のウインドウに刷新し、日本語と英語の画面を更新しました。
- 各タブの内容に合わせた高さを維持しながら、環境設定の切り替えを高速化しました。画面に収まらない場合も、スクロールで最後の項目まで表示できます。スクロール中は標準のスクロールバーが現れます。アクションの各リストは個別にスクロールできます。
- 履歴のグループ分け、重複処理、並び順、メニュー設定の動作を復元し、画像の拡大プレビューを追加しました。
- 標準のスニペットエディタで、フォルダの整理、検索、並べ替え、読み込み・書き出しができます。
- アクションのフォルダと修飾キー付きクリックの割り当てを編集できます。組み込み・同梱・ユーザー作成の JavaScript アクションに対応し、タブ切り替えや環境設定の再表示で編集内容が失われないようにしました。
- メニュー用のグローバルショートカットと自動ペーストを設定でき、アクセシビリティ権限の状態と設定用の操作を表示します。
- 記録する種類と除外アプリケーションを設定でき、テキスト、リッチテキスト、PDF、ファイル、URL、画像に引き続き対応します。
- Sparkle 2 と新しい更新フィードを採用しました。今回の手動インストール後は、対応する今後のリリースで更新・インストール・再起動を利用でき、プレリリース版の受信も選択できます。
