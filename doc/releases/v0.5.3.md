# ClipMenu 0.5.3

This patch removes the hidden clipboard-history shortcut and aligns the documentation with the two shortcuts available in Preferences. It supports **macOS 12 or later** on **Intel and Apple silicon** Macs.

**ClipMenu 0.5.0–0.5.2 users can update through Sparkle normally.** When upgrading from an older Objective-C version, quit ClipMenu and install this release manually; the original updater uses a different feed and trust key.

The app continues to use a local **ad-hoc code signature**, without Apple Developer ID signing or notarization. Published update ZIPs use separate Sparkle Ed25519 signatures.

## Changes

- Removed the hidden history-only shortcut, previously documented as Command–Control–V. Previously saved settings for that shortcut are ignored.
- The two supported menu shortcuts open the full ClipMenu menu (default **Command–Shift–V**) and the Snippets menu (default **Command–Shift–B**). Both can be changed in **Preferences → Shortcuts**. Clipboard history remains available in the full ClipMenu menu.
- Updated the README, acceptance cases, and shortcut localization to match the supported behavior. Historical verification notes identify the removed shortcut's earlier claims as obsolete.

## Validation

The Debug build passed. **51 focused tests passed with no failures**, and **six affected runtime reports passed** in an isolated Debug app. The runtime checks confirmed that only the two supported menu shortcuts are registered, including with legacy preferences.

環境設定に表示されない履歴専用ショートカットを削除し、利用できる 2 つのショートカットに合わせてドキュメントを更新したパッチリリースです。**macOS 12 以降の Intel Mac と Apple シリコン搭載 Mac** に対応します。

**ClipMenu 0.5.0〜0.5.2 からは Sparkle で通常どおり更新できます。** 以前の Objective-C 版から更新する場合は、ClipMenu を終了して、このリリースを手動でインストールしてください。従来のアップデータとは更新フィードと検証キーが異なります。

- これまで Command–Control–V として案内していた、環境設定に表示されない履歴専用ショートカットを削除しました。このショートカットの保存済み設定は無視されます。

- README、受け入れテスト項目、ショートカットに関する翻訳を現在の動作に合わせて更新しました。過去の検証記録には、削除したショートカットについての記述が現在は適用されないことを明記しました。
