# ClipMenu 0.5.1

This patch corrects the snippet editor's appearance and updates the fork documentation. It supports **macOS 12 or later** on **Intel and Apple silicon** Macs.

**ClipMenu 0.5.0 users can update through Sparkle normally.** When upgrading from an older Objective-C version, quit ClipMenu and install this release manually; the original updater uses a different feed and trust key.

The app continues to use a local **ad-hoc code signature**, without Apple Developer ID signing or notarization. Published update ZIPs use separate Sparkle Ed25519 signatures.

## Changes

- The snippet editor's folder background, empty state, and folder labels now follow the macOS light or dark appearance and refresh when the appearance changes.
- The README clarifies that this fork descends from the original 0.4.4a13 code and was modernized independently of the original project's 2014 Swift 1.0.0a1 alpha.
- The README screenshot gallery now starts with Menu preferences. Screenshots use PNG with transparent areas outside the rounded window corners, and the snippet editor screenshot reflects the corrected appearance.

## 日本語

スニペットエディタの外観を修正し、フォークの説明を更新したパッチリリースです。**macOS 12 以降の Intel Mac と Apple シリコン搭載 Mac** に対応します。

**ClipMenu 0.5.0 からは Sparkle で通常どおり更新できます。** 以前の Objective-C 版から更新する場合は、ClipMenu を終了して、このリリースを手動でインストールしてください。従来のアップデータとは更新フィードと検証キーが異なります。

アプリは引き続きローカルの**アドホック署名**を使用し、Apple Developer ID による署名や公証は行いません。公開する更新 ZIP は、別途 Sparkle の Ed25519 署名で検証します。

- スニペットエディタのフォルダ背景、未選択時の表示、フォルダ名が macOS のライト／ダークの外観に従い、外観の変更時にも更新されるようになりました。
- このフォークが元の 0.4.4a13 のコードを継承し、2014 年に公開された元プロジェクトの Swift 版 1.0.0a1 アルファとは独立して刷新されたことを README に明記しました。
- README のスクリーンショットを Menu 環境設定から始まる順序に変更しました。角が丸いウインドウの外側が透明な PNG を使用し、スニペットエディタの画像も修正後の外観に更新しました。
