ClipMenu 0.5.1

This patch corrects the snippet editor's appearance and updates the fork documentation. It supports Intel and Apple silicon Macs running macOS 12 or later.

Updating

ClipMenu 0.5.0 users can update through Sparkle normally. When upgrading from an older Objective-C version, quit ClipMenu and install this release manually; the original updater uses a different feed and trust key.

The app continues to use a local ad-hoc code signature, without Apple Developer ID signing or notarization. Published update ZIPs use separate Sparkle Ed25519 signatures.

What changed

  • Snippet appearance: the folder background, empty state, and folder labels now follow the macOS light or dark appearance and refresh when the appearance changes.
  • Fork history: the README clarifies that this fork descends from the original 0.4.4a13 code and was modernized independently of the original project's 2014 Swift 1.0.0a1 alpha.
  • Screenshots: the README gallery now starts with Menu preferences. Screenshots use PNG with transparent areas outside the rounded window corners, and the snippet editor screenshot reflects the corrected appearance.
