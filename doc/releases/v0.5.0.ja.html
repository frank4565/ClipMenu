ClipMenu 0.5.0

Swift で刷新した ClipMenu の最初のリリースです。macOS 標準のウインドウを採用し、macOS 12 以降の Intel Mac と Apple シリコン搭載 Mac に対応します。

このバージョンは手動でインストールしてください

以前の Objective-C 版から更新する場合は、ClipMenu を終了して、このリリースを手動でインストールしてください。従来のアップデータとは更新フィードと検証キーが異なるため、最初の Swift 版は従来の自動更新では配信できません。対応する旧形式の履歴、スニペット、アクション、環境設定は新しいアプリで読み込めます。

アプリはローカルのアドホック署名を使用します。初回起動が macOS にブロックされた場合は、Apple の起動手順に従い、このアプリに対して「このまま開く」を選択してください。公開する更新 ZIP は、別途 Sparkle の Ed25519 署名で検証します。

主な変更点

  • ウインドウの刷新：環境設定とスニペット編集を macOS 標準のウインドウに刷新し、日本語と英語の画面を更新しました。
  • 環境設定の応答性：各タブの内容に合わせてウインドウの高さを変えながら、タブ切り替えを高速化しました。画面に収まらない場合は高さを制限し、スクロールで最後の項目まで表示できます。スクロール中は標準のスクロールバーが現れます。アクションの各リストは個別にスクロールできます。
  • クリップボード履歴：履歴のグループ分け、重複処理、並び順、メニュー設定の動作を復元しました。画像の項目にポインタを合わせると、大きなプレビューを表示できます。
  • スニペット：標準のエディタでフォルダの整理、保存したテキストの検索、項目の並べ替え、読み込み・書き出しができます。
  • アクション：アクションのフォルダや修飾キー付きクリックの割り当てを編集し、組み込み・同梱・ユーザー作成の JavaScript アクションを利用できます。タブを切り替えても編集中の内容は保持され、確定したアクションは環境設定を開き直しても保持されます。
  • ショートカットとペースト：メニューを開くグローバルショートカットと自動ペーストを設定できます。アクセシビリティ権限の状態表示と設定用の操作を追加しました。
  • 記録対象の設定：保存するクリップボードの種類を選び、指定したアプリケーションを監視対象から除外できます。テキスト、リッチテキスト、PDF、ファイル、URL、画像に引き続き対応します。
  • 今後のアップデート：従来のアップデータを Sparkle 2 に置き換え、このフォークの新しい更新フィードを使用します。今回の手動インストール後は、対応する今後のリリースで更新・インストール・再起動の仕組みを利用できます。プレリリース版の受信も選択できます。
