ClipMenu 0.5.3

This patch removes the hidden clipboard-history shortcut and aligns the documentation with the two shortcuts available in Preferences. It supports Intel and Apple silicon Macs running macOS 12 or later.

Updating

ClipMenu 0.5.0–0.5.2 users can update through Sparkle normally. When upgrading from an older Objective-C version, quit ClipMenu and install this release manually; the original updater uses a different feed and trust key.

The app continues to use a local ad-hoc code signature, without Apple Developer ID signing or notarization. Published update ZIPs use separate Sparkle Ed25519 signatures.

What changed

  • Removed history shortcut: the hidden history-only shortcut, previously documented as Command–Control–V, is removed. Previously saved settings for that shortcut are ignored.
  • Two menu shortcuts: the full ClipMenu menu defaults to Command–Shift–V and the Snippets menu defaults to Command–Shift–B. Both can be changed in Preferences → Shortcuts. Clipboard history remains available in the full ClipMenu menu.
  • Documentation: the README, acceptance cases, and shortcut localization match the supported behavior. Historical verification notes identify the removed shortcut's earlier claims as obsolete.

Validation

The Debug build passed. 51 focused tests passed with no failures, and six affected runtime reports passed in an isolated Debug app. The runtime checks confirmed that only the two supported menu shortcuts are registered, including with legacy preferences.
